# Legal Matters Reference — James Bragdon

This file is used by Rocky's `--time-entries` command to match work tasks
(extracted from sent emails) to the correct Legal Matter for billing.

Rocky cross-references email recipients and subjects against the contact
persons, matter names, and descriptions listed here to propose matter
assignments for each time entry.

---

## How to use this file

For each active matter, add an entry with the fields below. The more detail
you provide (especially contact persons and their email addresses), the more
accurately Rocky can match tasks to matters.

---

## Template

### [Matter Number] — [Matter Name]
- **Client:** [Client Name]
- **Description:** [Brief description of the matter — type of case, key issues]
- **Contact Persons:**
  - [Name] — [role] — [email@domain.com]
  - [Name] — [role] — [email@domain.com]
- **Keywords:** [optional — distinctive terms, property addresses, docket numbers]
